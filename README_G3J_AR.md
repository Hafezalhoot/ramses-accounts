# رمسيس G3J — خط Cairo وطلبات مراجعة صرف الموردين

**نسخة تطوير واختبار فقط. غير معتمدة للتشغيل المالي أو الطبي الحقيقي.**

## تحديث تصميم الخط
تم اعتماد Cairo كعائلة خطوط واجهة النظام العربية عبر Google Fonts CSS2 Variable، مع تحميل ملف أنماطه **بعد اكتمال تحميل الصفحة** حتى لا تتعطل الواجهة في الأماكن التي لا يتوفر فيها إنترنت مع درجات `200–1000`، وتحديد أوزان واضحة للعناوين (800–900)، وأرقام المؤشرات (800)، والتبويبات والحقول (600–700)، والنصوص الطويلة (400). يبقى بديل الخط المحلي والعربي متاحًا تلقائيًا عند انقطاع الإنترنت. لا تُرفق أو تُوزع ملفات خطوط ضمن الحزمة؛ **تحميل Cairo فعليًا يتطلب وصول المتصفح لمصدر Google Fonts أو تثبيت Cairo محليًا**، وبالتالي اختيار `font-family` في Chromium لا يثبت تحميل ملف الخط عبر الإنترنت. سياسة CSP تتيح فقط النطاقين المحددين لملفات النمط والخط، وتبقي المصادر الأخرى محجوبة.

## ما تم إنجازه في G3J
* **طلب اعتماد صرف تمهيدي فقط** مربوط بقسط فاتورة مورد مطابق ومعتمد في G3I؛ يحدد التاريخ والمبلغ ومرجع المستند. لا يُنشئ أي قيد جديد أو حركة خزنة أو تحويل أو إثبات سداد.
* لا يمكن لموظف واحد اعتماد طلبه، ولا لمُعدّ فاتورة المورد أو محضر الاستلام أو جدول الاستحقاق اعتماده. تتحقق صلاحية المراجع في لحظة الاعتماد داخل المعاملة، وتمنع قاعدة البيانات التزوير عبر SQL مباشر.
* مجموع طلبات المراجعة المعلقة والمعتمدة لا يمكن أن يزيد عن قيمة القسط. إيقاف المورد يمنع اعتماد الطلب ولو كان قد أُعد سابقًا؛ الرفض ما زال متاحًا لإخلاء السعة. رفض الطلب يحرر السعة لإعادة التقديم بمستند جديد. المستندات المعتمدة والمرفوضة لا تُحذف أو تُعدّل.
* تظل تقارير الاستحقاقات **إجمالية قبل خصم المدفوعات**. الاعتماد التمهيدي ليس دينًا مسددًا ولا رصيدًا صافيًا بعد البنك.
* شهر مغلق يرفض إنشاء مستند جديد أو اعتماده، وشهر يحتوي مستندات طلب صرف معلّقة لا يُغلق قبل حسمها.

## التشغيل المحلي
استخدم `START_Ramses_Mac.command` على Mac إذا كان البرنامج يعمل عندك بهذه الطريقة. للاختبارات الاصطناعية: `python tests/test_v82_g3j_supplier_payment_requests.py` و`python tests/test_v82_g3j_upgrade.py` و`python scripts/ci_smoke.py`، مع وجود Python والحزم الموجودة بالمشروع. نتائج هذه الأوامر لا تحل محل اعتماد العمليات داخل المستشفى.

## حدود الأمان والاستكمال
لا يوجد في G3J سند صرف مورد موصول بفاتورة وبنك، ولا إثبات دفع/مخالصة، ولا تسوية خصومات وفروق ضرائب. **لا تدفع مستحقات فعلية أو تسجلها كمدفوعة اعتمادًا على هذا المسار.** المرحلة التالية تربط السند المالي المعتمد بالمرجع البنكي والمطابقة، مع عدم تكرار قيد الموردين والتحقق من الهوية وفصل المهام. ما زال مطلوبًا اختبار استعادة خارج الجهاز، الحصول على أرشيف V8.0 الأصلي، وعمل UAT موقع من الإدارة المالية والطبية وIT، واعتماد سياسة CSP وإتاحة الخط دون شبكة في مواقع العمل.
