# نظام حسابات مستشفى رمسيس — إصدار S10 | حالة اليومية مع أيام الإجازة

**للتجربة فقط — ليس مسموحًا تشغيله على عهدة أو مرضى أو دفتر أستاذ حقيقي.** هذا الإصدار يُحضَّر من سورس S9 على فرع مستقل؛ لا توجد أي عملية نشر للمستشفى.

## المشكلة الفعلية

كانت شاشة «اكتمال الورديات» تعرف أن نقطة كاشير معينة ليست مطالبة بأي وردية في يوم محدد حسب الجدول الرسمي (`not_required`). لكن شاشة «ملخص اليومية» كانت تشترط أن تكون **كل** نقاط الكاشير `complete` بلا استثناء؛ ولذلك كان ظهور إجازة أسبوعية معتمدة في نقطة واحدة يجعل يومًا مكتملًا في باقي نقاط التحصيل يظهر باعتباره غير مكتمل.

## الإصلاح

- أصبح شرط `shift_coverage_complete` يتعامل مع نقاط `not_required` كمراكز **غير مطالبة بالعمل أصلًا**، ويشترط وجود نقطة واحدة مطلوبة ومكتملة على الأقل.
- تستمر الحالات `missing` و`unclosed` و`awaiting_review` و`variance` و`in_progress` و`not_monitored` وغيرها في منع اعتماد اكتمال اليومية.
- يظل `financially_certified=false` حتى عند اكتمال الوردية: سلامة جدول التشغيل **ليست** اعتمادًا ماليًا أو إثباتًا لتسليم النقدية.
- عرض واجهة التغطية للأيام غير المطلوبة أصبح «يوم بلا ورديات مطلوبة» بدل الرمز الإنجليزي؛ لم نضف صفحة أو رخصة أو صلاحية أو قيدًا جديدًا.
- أصلحنا بيانات اختبار Chromium القديم لتعمل بحسب شهر القاهرة الحالي بدل أكتوبر 2026 الثابت، واحتفظنا بحالتي عرض الكمبيوتر والموبايل.

نفّذ في بيئة اختبار مستقلة (Python/FastAPI وChromium إن توفر):

```bash
python tests/test_s10_daily_coverage_certificate.py
python tests/test_shift_coverage_v81e_p0.py
python tests/browser_shift_coverage_offline.py
node --check static/app.js
python scripts/ci_smoke.py
python scripts/qa_g2t_full.py
S4_REAL_HTTP=1 python tests/test_s4_integrated_day.py
```

في اختبار S10 توجد نقطتان وهميتان: الأولى أغلقت كل الورديات المطلوبة، والثانية إجازة معتمدة حسب جدولها. يُفحص أيضًا يوم به ورديات ناقصة، ويوم بلا أي ورديات مطلوبة، ويوم غير مراقَب، ورفض طلب دون تسجيل دخول، وعدم إنشاء سندات أو حركات أو قيود من القراءة.

**مهم:** نجاح الاختبارات المحلية لا يثبت أن النقدية الفعلية سُلّمت أو أن إجراءات المستشفى وقّعت عليها. الرجوع إلى `docs/project-autopilot/TEST_REPORT.md` أو تقرير تسليم S10 لمعرفة العدد الفعلي للاختبارات وتفاصيل الحظر.
