# مستشفى رمسيس | حسابات V8.1E-G2X | تطوير واختبار فقط

هذه نسخة لاستكمال **صلاحيات ورديات الخزن المقيدة** مبنية على G2W (الذي قيّد قراءة ميزان المراجعة العام للمشاهد)، مع الحفاظ على تحسينات G2V الخاصة بالنسخ المشفرة قبل الترقية. **NO-GO للإنتاج**: لا تستخدم بيانات أو أرصدة أو صور مرضى أو موظفين حقيقيين.

## الذي تغيّر

- لا يرى المراجع ورديات الخزنة النقدية المقيدة أو حساب المحفظة/البنك وتفاصيل الجرد والمرفقات والملخصات إلا بتفويض قائم لهذا الحساب؛ تظل الورديات النقدية العامة في نطاق دور المراجع العادي.
- لا تكفي صلاحية `can_submit` لاعتماد جرد خزنة مقيدة: الاعتماد يتطلب `can_approve` فعالًا على نفس الحساب. سحب التفويض يسري في الطلب التالي.
- يغطي الفحص قوائم الورديات، تغطية الجدول، الملخص اليومي، المحاضر، مرفقات الجرد والتنزيل، محاضر فروق الجرد، سداد العجز المعروض، وخيارات الاعتماد.
- الواجهة ومشغّل Mac والخادم يعلنون جميعًا G2X بوصفه **Test Only**؛ لا يدّعي الموقع صلاحية الإنتاج.
- يوجد جرد آلي لواجهات API في `docs/project-autopilot/RBAC_ENDPOINT_INVENTORY_G2W.csv`، **تصنيف مبدئي وليس إثباتًا بأن جميع المسارات خضعت لمراجعة أمنية مستقلة**.

## فتح نسخة اختبار معزولة على Mac

1. فك ZIP في مجلد اختبارات مستقل. **لا تنسخ فوق مجلد أو قاعدة بيانات النظام الأصلي**.
2. نفّذ تعليمات `README_G2V_AR.md` لتحضير مفتاح تشفير قوي ومجلد قاعدة اختبار منفصل، ثم شغّل ملف `START_Ramses_Mac.command` بعد مراجعة إعداداته.
3. احتفظ بالأرشيف السابق وGit Bundle وملف SHA-256 منفصلين. أي ترقية لقاعدة قديمة تتطلب مفتاح النسخ الاحتياطي الآمن، ولا يجوز تجاوز القيد لكي تفتح النسخة.
4. تحقق من الإصدار الظاهر في صفحة الدخول وتذييل الموقع، ومن `/health` عند تشغيل خادم الاختبار.
