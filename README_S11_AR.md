## ما تغير فعليًا

- إنشاء المستخدم والموظف والخزنة وربطها بالأستاذ وسجل التدقيق أصبح معاملة واحدة؛ فشل سجل التدقيق يرجع الإنشاء كله. اختبار SQLite حقيقي أثبت الفشل قبل الإصلاح والنجاح بعده.
- طلب صرف مستلزمات معلق مرتبط بحالة المريض يمنع إقفالها المالي، في وضع التسوية أو الإلغاء دون رسوم، ويُعاد فحصه عند اعتماد المراجع. يحمي ذلك من ترك مستند صرف لا يمكن حسمه بعد إقفال الحالة ثم تعطيل إقفال الشهر.
- اليومية تعرض الورديات غير المسجلة أو المنتظرة للمراجعة والمتابعة المطلوبة، ضمن صلاحيات المستخدم. الحالات غير المرصودة والمواعيد القادمة تظل واضحة. يظهر تنبيه دائم بأن الملخص لا يمثل اعتمادًا ماليًا أو إثباتًا لتسليم النقدية.
- 48 سكربت متصفح أصبحت تختار Chromium/Chrome المتاح بدل افتراض مسار Linux. يمكن ضبط `RAMSES_BROWSER_EXECUTABLE`، أو تثبيت Chromium الخاص بـPlaywright.
- تحديث `cryptography` إلى `50.0.2` بعد فحص ثغرات فعلي، وتحديث pip في بيئة العمل ومسار Docker/CI. جرى اختبار استعادة نسخة مشفرة أُنشئت بـ46.0.7 عبر50.0.2 مع تطابق المخطط والبيانات منطقيًا. راجع نتيجة الفحص النهائية في التقرير.

لا يضيف هذا الإصدار دورة أطباء أو تأمين أو ضرائب أو سياسة استحقاق مفترضة. تفاصيل الموجود والناقص والموانع الفعلية في [المراجعة الشاملة](docs/project-autopilot/S11_COMPREHENSIVE_REVIEW_AR.md).

## إعادة الاختبارات

استخدم Python64bit وبيئة افتراضية منفصلة. اختُبرت هذه المرحلة على macOS ARM64/Python3.13؛ بناء Docker/Linux ومعدات المستشفى غير مختبرين هنا. ثبّت الاعتماديات من `requirements.txt`، وPlaywright للاختبارات المرئية فقط. لقطة الإصدارات المستخدمة في `docs/project-autopilot/evidence/S11/runtime-freeze.txt` تشمل أدوات الاختبار والفحص أيضًا.

```bash
python -m pip install 'pip>=26.3,<27'
python -m pip install -r requirements.txt playwright
python -m playwright install chromium
export RAMSES_V80_ARCHIVE='/path/to/original/Ramses_Accounts_V8_0_Double_Entry_Decision_Foundation.zip'
python scripts/ci_smoke.py
python scripts/qa_g2t_full.py
python scripts/qa_s11_http.py
S4_REAL_HTTP=1 python tests/test_s4_integrated_day.py
python tests/browser_s11_daily_exceptions.py
```

الأرشيف التاريخي للاختبار منفصل عن حزمة الإصدار. بصمته `4a4db9de12b3f21b93310248cfa0b3c000c750d8bcf13561db3a361924fa62cb`. نجاح الترقية منه يتعلق بمخطط تاريخي وبيانات مصطنعة، ولا يعوض ترحيل قاعدة تشغيل حقيقية أو توقيع أرصدة افتتاحية.

السكربت الشامل يكتب `QA_G2T_TEST_RESULTS.tsv`؛ احفظ نتيجتك باسم المرحلة حتى لا تُستبدل أدلة قديمة عند التسليم. لا تُحسب SKIP نجاحًا.
