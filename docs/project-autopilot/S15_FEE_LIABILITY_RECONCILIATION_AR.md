# S15A — مطابقة أتعاب الخدمات المعتمدة مع حساب 2320

**TEST ONLY / NO-GO** — مراجعة محاسبية للقراءة فقط، وليست سند صرف أو اعتمادًا ماليًا نهائيًا.

## سبب المرحلة

S14 يرحّل أتعاب الخدمات المعتمدة إلى Dr 5196 / Cr 2320 ويتيح عكس الاعتماد بقيد منفصل، لكنه لا ينفذ سداد المستحق. قد تختلف قرارات الاعتماد عن الأستاذ، أو توجد قيود مجهولة متعاكسة تخفي الاختلاف عند مقارنة الإجماليات فقط.

## نطاق التنفيذ

- `service_fee_reconciliation.py::reconcile_fee_liability(connection)`: يقرأ الرصيد المرحّل لحساب 2320 وصافي الاعتمادات غير المعكوسة بالقروش.
- `GET /api/service-fees/payables-reconciliation`: مسار قراءة للمالك فقط، يمر من صلاحيات الجلسة الحالية.
- التحقق من وجود الحساب وصحة نوعه، وربط كل اعتماد بقيد مرحّل بالقيمة الصحيحة، وربط كل عكس بقيد مرحّل معاكس، وعدم وجود قيود مجهولة، ومنع قبول قيود تحتوي أكثر من سطر في 2320.
- `matched` مؤشر مطابقة فنية فقط؛ `certified=false` دائمًا. لا قسيمة صرف ولا قيد جديد ولا تغيير خزنة.
- لا تعتمد المقارنة على أخذ عينة من الواجهة، ولا تُنشئ حسابات أو تغيّر سجلًا أثناء طلب القراءة.

## نتائج التطوير وحدود التحقق

تم إجراء TDD محلي مع SQLite اصطناعي: فشل اختبار الاستيراد قبل إضافة الوحدة، ونجح بعدها. أضيف اختبار لقيدين متعاكسين في نفس اليومية وفشل أولًا ثم نجح بعد فحص عدد الأسطر. اختبار `pytest` للوحدة نجح. لا يُحسب ذلك نجاحًا لاختبارات مشروع S14 بالكامل.

**لم يتم** تشغيل `tests/test_s14_service_fees.py` أو `scripts/ci_smoke.py` أو `scripts/qa_g2t_full.py` على نسخة S14 المستنسخة: بيئة التنفيذ الحالية لا تستطيع الوصول إلى GitHub مباشرة بسبب DNS. GitHub connector يسمح بالمراجعة والكتابة وإصدار PR لكن لا ينفّذ Python داخل المستودع.

## تعزيز S15 — تحقق طرفَي القيد المحاسبي (5 نوفمبر 2026)

أُضيف تحقق مستقل من كل قيد اعتماد أو عكس: يجب أن تكون اليومية **بسطرين بالضبط**، بحيث يكون الاعتماد **مدين 5196 / دائن 2320** بالمبلغ الكامل، والعكس **مدين 2320 / دائن 5196** بالقيمة نفسها. ويُشترط بقاء حساب مصروف الأتعاب 5196 من نوع `expense` ونشطًا وغير رقابي. التوازن الرقمي وحده لا يكفي.

تمت إعادة إنتاج الخلل على نسخة مطابقة بصمتها لملف S15 المصدر قبل التصحيح: **3 حالات متوازنة محاسبيًا أُبلغ عنها خطأً بأنها `matched=true`**. أضيفت حالتان أخريان تكشفان تعطيل حساب 5196 أو تغيير نوعه. بعد التصحيح اجتازت **6/6** اختبارات اصطناعية محلية، مع اجتياز فحص صياغة Python. الاختبار الجديد `tests/test_s15_fee_counterparty_controls.py` متاح للتشغيل المباشر ضمن `scripts/ci_smoke.py`.

**حدود الدليل:** هذه اختبارات وحدة SQLite اصطناعية وليست اختبار تكامل لكل سورس S14 أو إثباتًا لترحيل/صرف حقيقي. لا دمج أو نشر إنتاجي قبل إعادة اختبار PR #3 عبر مشغّل الاختبارات الخارجي المعتمد، مع استمرار تعطيل GitHub Actions.
