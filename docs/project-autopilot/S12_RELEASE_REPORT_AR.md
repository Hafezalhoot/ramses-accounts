# S12 — تقرير الإصلاحات والتقييم الحالي

**التاريخ:** 4 نوفمبر 2026 ، القاهرة. **الحالة:** مرحلة تطوير محلية مكتملة الفحوص المذكورة، ومعاينة خارجية ببيانات وهمية؛ التشغيل الفعلي للمستشفى ما زال NO-GO.

### الفشل الذي ظهر أثناء العمل

- اختبار HTTP الجديد استعمل أولًا وسيط`content` الذي يدعمه TestClient ولا تدعمه requests ؛ صُحح طلب JSON ليعمل على الناقلين. لا أُعلن نجاح TCP إلا بعد الإعادة الناجحة.
- محاكاة فقد التخزين نقلت أولًا ملف DB وحده وأزالت WAL/SHM ، فأفسدت معنى تجربة الاستعادة عبر عملية مستقلة. صُححت لنقل المجلد كاملًا؛ اختُبر الفشل مجددًا على سورس S11 غير المعدل، ثم نجحت الحالة على S12 و TCP.
- فشل تهيئة المعاينة مع Secure رُصد عند تشغيلها فعليًا ثم أثبته اختبار مستقل قبل الإصلاح.
- الرابط بالبريد نجح عند بوابة GET للمجهول، ثم أبلغ المستخدم عن 401 أثناء دخول البرنامج. لذلك لم يعد فحص 302 وحده دليل جاهزية. لم يصل POST الذي فشل إلى سجل التطبيق، وأعراضه متوافقة مع بلاغ المزود؛ لم يدّع المشروع إصلاح كود Cloudflare.
- ضبط Apache الأولي واجه منع قراءة Documents وقفلًا افتراضيًا في`/var/run`؛ أُبقيت ملفات البوابة في مجلد مؤقت خاص. وضع العامل التشخيصي الواحد أدى إلى مهلة Chrome ؛ ضبط عمال محدودين أعاد نجاح ملفات المتصفح. المحاولة المرئية الأولى الفاشلة محفوظة في`external-browser.log`، والنتيجة النهائية في الملف الموضح أعلاه.

## حدود المعاينة الحالية

- بيانات اصطناعية فقط. لا تُعرض قاعدة المستشفى أو حسابات تشغيل أو مفاتيح خارجية. لم تُرسل رسالة إلى طرف ثالث أو تُشترَ خدمة مدفوعة.
- البديل يتحقق بكلمة مرور مستقلة قبل التطبيق؛ لا يمثل OTP بالبريد أو MFA. الأسرار وملفات bcrypt والعمليات وقواعد البيانات موجودة في مسارات خاصة مستبعدة من السورس. كلا المنفذين محلي 127.0.0.1 فقط، والنفق يوجه إلى البوابة.
- الفحص الخارجي أثبت نجاحًا فعليًا في Chrome، لكنه لا يجعل الجهاز استضافة دائمة أو يثبت اختبار معدات المستشفى والطابعات والشبكة الداخلية أو توقيع الموظفين. حالة المشروع لا تسمح باستخدام الرابط للإنتاج.
- القالب الخاص بالنشر التجريبي في [دليل البوابة](S12_PASSWORD_PREVIEW_AR.md). لم تجر هنا اختبارات Docker/Linux أو فحص CVE شامل لـApache ونظام التشغيل؛ الفحص الآلي المذكور خاص باعتماديات Python.

الأجزاء المالية ذات السياسة لم تُعلن مكتملة لمجرد نجاح الاختبارات. كل شريحة تحتاج مصدرًا وصلاحية ومراجعة وقيدًا ودفترًا مساعدًا ومطابقة وقبولًا؛ إضافة صفحة وحدها لا تغلق دورة مالية.
