# نظام حسابات رمسيس V8.1E-G3G — شطب المستلزمات المرتجعة المرفوضة طبيًا

**نسخة تطوير واختبار فقط. لا تستخدمها في العمليات المحاسبية أو الطبية الحقيقية (NO-GO).**

## ما أضيف مقارنةً بـ G3F

- **رفض طبي مستقل → حجر → مستند تلف/إعدام مع إقرار إزالة فعلية → اعتماد مالي من شخص آخر.** الرفض الطبي وحده لا يخفض أصل المخزون، والإعداد وحده لا يرحّل أي قيد.
- يدعم الشطب الجزئي للوحدات المرتجعة من نفس تخصيص دفعة FIFO الأصلية، ويمنع أن يتجاوز مجموع المستندات المعلقة والمعتمدة كمية السطر المرفوض.
- عند الاعتماد فقط: **مدين 5195 (خسائر تلف وإعدام مستلزمات مخزون) / دائن 1100 (المخزون)** بتكلفة الوحدة التاريخية نفسها؛ لا يُعدّل مرتجع الحالة الأصلي ولا إيرادات/فواتير المريض ولا يُسجل نقدية.
- تمنع قاعدة SQLite مباشرةً تغيير السندات النهائية، أو تجاوز العدد، أو إقفال الشهر مع طلب تلف معلق، أو ترحيل تسوية دون اعتماد مراجع مستقل وقيد متزن مرتبط بالسند.
- شاشة المخزن RTL تُظهر مستندات التلف وطابور المستلزمات المرفوضة بأسماء الأصناف والتشغيلات فقط؛ لا تعرض اسم المريض أو ملفه أو ملاحظات الفحص السريري.
- الترقية من **مخطط G3F الأصلي** تضيف الجدول والتريجرات وحساب 5195 بعد نسخ احتياطي مشفر قبل تعديل المخطط؛ لا تُنشئ تسويات مزيفة للوحدات التاريخية.

## تجربة عملية ببيانات وهمية

1. فك ZIP الجديد في مجلد مستقل، استخدم متغير `RAMSES_DB_PATH` لمسار قاعدة تجريبية جديدة، وابدأ وفق `README_AR.md`. **لا تفتح قاعدة المستشفى الفعلية**.
2. سجل موردًا وصنفًا غير دوائي، واستلم كمية بسند، واعتمد الاستلام عبر مراجع مختلف، ثم أصدر إذن صرف لحالة وهمية واعتمده.
3. سجل مرتجعًا من تخصيص FIFO المعتمد، ثم اعتمده ماليًا. سيعود أصلاً محاسبيًا إلى المخزن لكن يظل بالحجر الطبي.
4. أدخل كطبيب تجريبي ذي تفويض قسم سارٍ؛ اختر «رفض» للمرتجع مع مستند فحص. **لا تسمح هذه الخطوة بالشطب تلقائيًا.**
5. من حساب موظف مخزن لديه إعداد، افتح قسم «طلب شطب مستلزم محجوز»، واختر المرتجع المرفوض والعدد الفعلي والسبب وتاريخ الإزالة ومحضرًا موقعًا. ضع علامة تأكيد الإزالة المادية في **الاختبار فقط**.
6. تحقق أن المخزون والقيمة لم يتغيرا قبل القرار. ادخل بمراجع مستقل لديه اعتماد المخزن، واعتمد المستند؛ يجب أن ينخفض عدد الحجر وقيمة المخزون فقط بكمية التسوية، ويظهر القيد Dr5195/Cr1100. عند رفض الطلب لا تتغير القيود أو الأرصدة.
7. جرّب تجاوز الكمية، واعتماد نفس المستند مرتين، سحب التفويض، شهرًا مقفلاً، وفتح قائمة الطبيب كمحاسب. يجب منع كل الحالات غير المخولة.

## ما يزال غير معتمد

- لا تعادل علامة «تمت الإزالة» محضر إعدام معتمدًا أو وجود سياسة مكافحة عدوى أو لجنة جرد فعلية، وليست هناك شهادة سلامة أو ترخيص للفاحص؛ يجب اعتماد سير العمل ميدانيًا قبل أي تنفيذ.
- لا معالجة لأدوية أو زرعات معرّفة برمز UDI أو سلاسل تبريد أو أجهزة تتطلب إعادة معالجة، ولا قيود إهلاك أو معالجة تلقائية للضرائب.
- الدفعات التاريخية التي أُعيد صرفها في G3E قبل إثبات الفحص الطبي تظل محجوبة لحين جرد فعلي وتسوية خاصة؛ لا تجرى إعادة كتابة لتاريخ GL.
- المرحلة القادمة: أوامر الشراء والمطابقة الثلاثية بين الأمر والاستلام والفاتورة، ثم الذمم والتسويات مع الموردين. لا تُنشأ مدفوعات أو تحويلات في G3G.
- الشروط المانعة للإنتاج: أرشيف V8.0 الأصلي، استعادة مشفرة على جهاز مستقل، اختبار LAN/الصلاحيات داخل المستشفى، قبول الإدارة الطبية والمالية وIT بتوقيعات مكتوبة.
