# رمسيس — النسخة التجريبية G2U بعد مراجعة G2T

**تحذير:** برنامج تجريبي للتطوير والاختبارات الاصطناعية فقط. **ممنوع استخدام بيانات المرضى أو التحصيل/الصرف الحقيقي.** لا توجد نسخة منشورة على سيرفر المستشفى من هذا التطوير.

## فتح النسخة على macOS

1. فك ضغط ملف `Ramses_Accounts_V8_1E_G2U_Stabilization_Development_Test_Only.zip` في Finder، ولا تحاول تشغيل ZIP نفسه.
2. افتح مجلد `ramses_accounts`، وشغّل `START_Ramses_Mac.command` باختيار الوضع التجريبي المحلي (1). يلزم Python 3.11 أو أحدث، وقد يطلب تثبيت مكتبات Python.
3. بعد ظهور عنوان الخادم في Terminal، افتح `http://127.0.0.1:8000` في متصفح الجهاز. اترك Terminal مفتوحًا طوال مدة التجربة.
4. لو منع macOS فتح الملف: راجع `HOW_TO_OPEN_ON_MAC_AR.txt`؛ استخدم `bash START_Ramses_Mac.command` من داخل المجلد أو `chmod +x` مع التأكد من مصدر الملف، دون تعطيل Gatekeeper.

**لا تنسخ أي قاعدة بيانات تشغيل حقيقية إلى هذه النسخة.** جميع الاختبارات المكتوبة تعمل على ملفات SQLite مؤقتة بمستخدمين ومبالغ افتراضية.

## ما الجديد؟

- فصل تاريخ دخول المريض عن تاريخ ليلة الإقامة وتاريخ ترحيل فاتورتها.
- إسناد سعر الخدمة العادية إلى تاريخ تحقق التنفيذ، وحفظ سعر ليلة السرير المؤرخة.
- ضبط فحوص إقفال الفترة ومطابقة الفواتير غير الصادرة مع شهر الخدمة، لا شهر دخول المريض.
- حماية مسارات محددة من كشف بيانات موظفين وأرصدة خزائن ومستندات بنوك غير مفوضة، بما فيها قوائم الاعتماد والتصدير والمرفقات.
- Migration إضافية متحفظة للمخطط: الخدمة القديمة مجهولة التاريخ لا يخترع النظام لها تاريخًا جديدًا.

## الدليل الفني والتجريبي

- `RAMSES_V81E_G2U_STABILIZATION_QA_AR.md`: ما نُفذ، شروط الفترة، حدود الأمان، والمهام التالية.
- `QA_G2U_TEST_RESULTS.tsv`: نتائج كل سكربت اختبار، بما فيها الاختبارات المحجوبة والمتخطاة.
- `QA_G2U_CI_RESULTS.txt`: بوابة الاختبارات السريعة.
- `RAMSES_G2U_FINDINGS_TRACKER.json`: سجل المخاطر المحدث لكل ملاحظة G2T.
- `BUILD_MANIFEST_V81E_G2U.json`: بصمات SHA-256 لكل ملف في الحزمة.

يظل قرار التشغيل الحقيقي **NO-GO** حتى استكمال دور إثبات الخدمة الطبية المستقل، صلاحيات كافة التقارير، النسخ والاستعادة الآمنة، دورة الموردين والمخازن، الأطباء والتأمين والضرائب، ثم تجارب وأذونات التشغيل المعتمدة.
