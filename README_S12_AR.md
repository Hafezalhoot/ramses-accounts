**4 نوفمبر 2026 — بيانات وهمية واختبارات فقط — PRODUCTION NO-GO.**

المصدر مبني على S11 `0acb2db3aea4dd0de8f2debf880e221dc824b31b`، على فرع `stabilization/s12-request-limits-preview`، مع حفظ تاريخ المشروع السابق.

## المنفذ في هذه المرحلة

1. حد إجمالي للطلب **7 MiB** قبل تحليل JSON أو multipart ؛ يسمح بمرفق **6 MiB** مع بيانات تغليف الطلب. الطلب المعلن الأكبر يُرفض قبل إنشاء ملفات مؤقتة، والطلب المتدرج دون طول صحيح يُقاس أثناء القراءة. حد الملف نفسه يظل 6 MiB. لا تتحول الطلبات المرفوضة إلى حركات مالية.
2. اتصالات قاعدة البيانات أثناء التشغيل تستخدم فتح ملف موجود فقط `mode=rw`، دون إنشاء ملف أو مجلد بديل عند فقد التخزين. يعاد 503 برسالة واضحة، مع معالجة آمنة للمسارات العربية والرموز `#` و`?`. إنشاء قاعدة جديدة يظل من مسار التهيئة الصريح.
3. تهيئة بيانات المعاينة المحمية أصبحت تستخدم عنوان HTTPS داخل TestClient ، حتى تعمل ملفات الجلسة Secure دون تعطيلها. يُنشأ الديمو من خلال واجهات النظام، ويُرفض تكرار إنشائه.
4. تثبيت FastAPI0.162.0 و Starlette1.10.0 و python-multipart0.0.33 ، وهي النسخ المختبرة هنا. تنظيف الملفات الجزئية عند انقطاع stream يعتمد على سلوك محلل الطلبات؛ لا ندعي دعم الإصدارات القديمة التي لم تختبر.
5. بديل معاينة خارجي محمي بكلمة مرور مستقلة أمام التطبيق، بعد أن وصلت الصفحة عبر بوابة البريد بينما رفضت طلبات POST قبل وصولها للتطبيق. اختُبر البديل عبر HTTP و Chrome على HTTPS فعلي، وليس بجسر ASGI وحده.

## المعاينة

المعاينة الحالية **مؤقتة** وتعمل من جهاز التطوير على بيانات مصطنعة. بيانات البوابة والتطبيق تحفظ في ملف خاص `private/PREVIEW_ACCESS.txt` على الجهاز، وتُستبعد هي وملفات الإعداد والمفاتيح وقواعد البيانات من Git وحزمة السورس. عنوان المعاينة يتغير عند إعادة إنشاء النفق، وينتهي عند إغلاقه أو انقطاع الجهاز.

للجهاز نفسه:

```bash
python scripts/free_preview.py --local-only --demo
```

للمعاينة الخارجية بطريقة كلمة المرور المستقلة: راجع [دليل البوابة](docs/project-autopilot/S12_PASSWORD_PREVIEW_AR.md). لا توصل نفقًا خارجيًا مباشرة بالتطبيق دون بوابة الحماية. قالب Apache المرفق خاص بمسار macOS المختبر، وليس إعداد استضافة إنتاجية عامة.

مسار بوابة البريد القديم ما زال موجودًا في `free_preview.py`؛ الخلل الخارجي موثق في تقرير المرحلة ولا يُعتبر محلولًا لدى المزود. البديل الحالي يحافظ على حظر الزوار بكلمة مرور قبل التطبيق.

## ما لم يكتمل

سياسة إيراد الإقامة العابرة للشهر ومراجعة 2200 تحتاجان اعتمادًا ماليًا واضحًا؛ المقترح محفوظ ولم يُفعّل. ما زالت دورات الأطباء والتأمين والضرائب والأصول والإقفال السنوي والمخازن المتعددة والجرد الفعلي غير مكتملة، إضافة إلى ترحيل بيانات المستشفى وأرصدة افتتاح موقعة، والتعافي على جهاز مستقل وتجربة الطابعات و LAN/HTTPS على المعدات الفعلية وتوقيعات UAT. لا يثبت رابط المعاينة جاهزية المستشفى للإطلاق.
